# Contributing to MDST

Thank you for your interest in MDST.

## Scope

MDST focuses on:

- CRT decomposition
- Dynamics over finite rings
- Idempotent classification
- Functional graph analysis
- Basin partitioning
- Computational implementations

## Guidelines

- Keep commits atomic and descriptive.
- Preserve mathematical consistency.
- Include reproducible examples when possible.
- Avoid introducing unsupported claims.
- Prefer documented algorithms over speculative implementations.

## Documentation

All theoretical additions should include:

- Definitions
- Assumptions
- Complexity notes
- Examples when applicable

## Licensing

By contributing, you agree that your contributions will be released under the repository licenses:

- MPL-2.0 for code
- CC BY 4.0 for theoretical documentation
